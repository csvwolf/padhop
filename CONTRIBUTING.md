# Contributing

Use Windows x64 and run `scripts/build.ps1` plus `scripts/test.ps1 -Python <python.exe>`. Keep patches focused and describe both offline validation and hardware tests actually performed. Do not claim hardware compatibility from synthetic tests alone.

Never commit profiles, raw HID/Bluetooth captures, personal paths, binaries, or signing keys. Use synthetic device identities in fixtures. Preserve third-party notices when adapting algorithms. Contributions are submitted under the project's MIT license.
